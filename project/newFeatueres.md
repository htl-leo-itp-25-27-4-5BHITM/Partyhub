# Neue Features für PartyHub

## Favourite Partys
Interessante Partys als Favoriten speichern und in einer eigenen Merkliste wiederfinden, ohne direkt zuzusagen. So können Nutzer später entscheiden, ob sie teilnehmen möchten.

## Ankündigungen vom Host
Der Host kann wichtige Hinweise direkt bei der Party veröffentlichen, etwa „Der Eingang ist im Innenhof“. Teilnehmer erhalten dazu eine Benachrichtigung in ihrer Inbox.

## Warteliste
Ist eine Party voll, können sich Nutzer auf eine Warteliste setzen und bei einer Absage einen Platz angeboten bekommen. Dafür müsste die maximale Teilnehmerzahl verbindlich begrenzt werden.

## Mitbringliste
Der Host erstellt eine Liste mit benötigten Dingen und Mengen, zum Beispiel Getränken oder Snacks. Gäste können Einträge übernehmen, sodass alle sehen, wer was mitbringt und was noch fehlt.

## Wiederkehrende Partys
Der Host kann regelmäßige Partys erstellen, zum Beispiel einen Spieleabend jeden Freitag. Die Termine werden automatisch angelegt, sodass nicht jede Party einzeln erstellt werden muss.

## Entwürfe speichern
Der Host kann eine Party als Entwurf speichern und später weiterbearbeiten, bevor sie veröffentlicht wird. Der Entwurf ist nur für den Host sichtbar, sodass auch unvollständige Angaben gespeichert werden können.
